# Runner App and the BMAD Method

**A running app built by a team of AI agents, with a human in charge.**

## What this project is

This project has two goals:

1. **Build a useful running app.** Most running apps record your runs and cheer you on. This one aims to get you to the finish line, injury-free. It helps runners follow a training plan, understand whether they're on track for their race goal, and adjust when their body or race conditions call for it.
2. **Show what agentic AI can do when it's used responsibly.** The app is being planned, designed and built with the [BMAD Method](https://github.com/bmad-code-org/BMAD-METHOD), an open-source framework that organises AI agents into a project team. Each agent has a role, such as business analyst, product manager, architect, UX designer or developer.

## How it works

I'm the **Vibe CEO**. The AI agents do the work. I make the decisions, review what they produce, and step in whenever a human needs to take over.

The project follows a few principles:

- **Human in the loop.** Agents propose; a human decides.
- **Full transparency.** Project decisions are written down in the project documents, so anyone can see how and why the app took shape.
- **$0 to build and run.** The project uses only free tools and platforms.
- **Readable code.** The code should be easy to understand, with plain-English comments.
- **Agile delivery.** A small working version comes first, and features are added in later sprints.

## What's in this repository

This repository holds the files the BMAD agents produce along the way, from brainstorming and planning documents to, eventually, the app itself. They're shared openly so you can follow the process from idea to working product.
